# Windows NTFS source discovery

The builder manifest supports ordinary Windows files and directories from drive-letter paths to local, Mount Manager-backed NTFS volumes. Root admission checks the filesystem name and the volume GUID path from the same opened root. Mapped shares and substitute drive roots fail this check. NTFS on removable media is outside the current verification scope. Ordinary drive paths resolve `..` lexically. Verbatim drive paths reject `.` and `..` components. The adapter rejects alternative namespaces, alternate data streams, ambiguous trailing dots and spaces, and all reparse entries including symlinks and junctions. Explicit image symlink declarations continue to carry their configured bytes. [Windows volume path API](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-getfinalpathnamebyhandlew)

Below the volume root, each name is opened relative to its held parent without following reparse points. Directory enumerations query a held directory handle into bounded, checked batches. Reopens compare the original NTFS volume serial and file index, native attributes, size, link count, last-write time, creation time, and change time. Access time is observed for metadata but omitted from mutation comparisons because reading can update it. The NTFS identity and link count come from `GetFileInformationByHandle`. The four timestamps use `FileBasicInfo` and convert 100 ns units since 1601 into signed Unix seconds and nanoseconds. An unavailable time stays absent. POSIX permissions, ownership and BSD flags stay absent. Required preservation reports the unavailable POSIX fields in report mode and fails in strict mode. [NTFS file information](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/ns-fileapi-by_handle_file_information), [Windows basic file information](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_basic_info)

D-BUILD-02 Windows tests exercise ordinary paths, filters, empty directories, hard-link IDs, output alias rejection, mutation and junction refusal, alternate-stream rejection, and resource limits.
